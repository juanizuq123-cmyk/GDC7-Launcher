# Canal estable del perfil GDC7

GitHub Pages sirve `stable.json` desde esta carpeta. Es el manifiesto completo
firmado del perfil y referencia archivos en la release inmutable
`gdc7-profile-<versión>`. El cliente comprueba firma, rutas, tamaño y SHA-256 /
SHA-512 antes de escribir en una instancia marcada GDC7.

La release del perfil y la del launcher tienen claves y versiones
independientes.
